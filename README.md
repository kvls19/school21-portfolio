## Первый проект: Linux

На практике прошёл базовый цикл настройки сервера: установка ОС, управление пользователями, настройка сети, удалённый доступ и проверка работы служб. Разобрался с процессами, дисковым пространством и системными журналами; настроил периодический запуск команды через cron.

[Описание проекта](01-linux-administration/README.md) · [Полный отчёт со скриншотами](01-linux-administration/docs/report.md)

## Второй проект: сети в Linux

Развернул основную сеть из пяти виртуальных машин — трёх рабочих станций (ws11, ws21, ws22) и двух маршрутизаторов (r1, r2). Настроил связь между подсетями, динамическую выдачу адресов, фильтрацию трафика и проброс порта к Apache. Проверил маршруты через traceroute и tcpdump, измерил пропускную способность и настроил доступ к веб-серверу через SSH-туннели.

[Описание проекта](02-linux-network/README.md) · [Полный отчёт со скриншотами](02-linux-network/docs/report.md)
